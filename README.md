# Лабораторная работа 1 по криптографии

**Вашему вниманию представлена лабораторная работа с реализацией методов шифрования на основеи XOR, AES-ECB и AES-CTR**

## Инструкция

Убедитесь, что у вас установлен Python версии 3.13+

Перед запуском выполните следующую команду:

``` powershell
python -m pip install numpy pillow pycryptodome matplotlib
```

и очистите кэш командой


```powershell
python -m pip cache purge
```

Файл для запуска - **main.py**. В нем уже есть все необходимые зависимости.

**Важно:** если хотите поменять алгоритм или изображение, в файле **meta.json**

```meta.json
{
    "algorithm": "xor",
    "nonce": "f3e96ef494f55153",
    "source": "gradient.png"
}
```

необходимо поменять 2 строки - "algorithm" и "source". Доступно 3 алгоритма:
- xor
- aes-ecb
- aes-ctr

Название алгоритма пропишите **обязательно строчной латиницей**, иначе изображения не дешифруются и не зашифруются

Результаты выполнения работы записываются в следующие папки:
- encrypted/
- recover/
- results/ (в этой папке лежат диаграммы)

Запустите программу командой

```
python ~/lab-01-crypto/src/main.py
```

**Приятного использования!**
