## Лабораторная работа 1. Теоретическая часть

Сегодня на рассмотрении алгоритмы криптографического шифрования AES-ECB, AES-CTR и базовый алгоритм на основе XOR.

**AES** — симметричный блочный шифр: шифрует данные блоками по 128 бит с ключом 128, 192 или 256 бит. Широко используется для защиты данных.

Конкретно в нашей работе рассматриваются 2 варианта AES:
- ECB-алгоритм (128-битный блок шифруется независимо одним и тем же ключом)
- CTR-алгоритм ( шифруются последовательные значения счётчика (с nonce), результат XOR-ится с данными)

**XOR** - простейший симметричный метод: каждый бит/байт открытого текста складывается по модулю 2 (XOR) с соответствующим битом/байтом ключа (или гаммы). Шифрование и расшифрование — одна и та же операция

Начнем разбор с алгоритма **XOR**

Первое, что мы сделали - написали класс xorshift32 как исходный генератор псевдослучайной последовательности. Ознакомиться вы с ним можно в папке проекта **/src/xorshift32.py**

В данном классе все реализуется в блоках ''\_\_init\_\_'' и ''next''. Все основывается на двух операциях:
- Побитовый сдвиг влево/вправо (>> и << соответственно)
- Операция XOR (побитовое исключающее ''или'')

```python
class xorshift:
    def __init__(self, seed: int):
        if seed == 0:
            seed = 1
        self.state = seed & mask

    def next(self):
        x = self.state
        x ^= (x << 13) & mask
        x ^= (x >> 17)
        x ^= (x << 5) & mask
        self.state = x & mask
        return self.state
```

**Важно:** мы использовали Crypto.~, так как он является частью библиотеки pycryptodome

**2. Шифрование/дешифрование по AES-ECB**

```python
def aes_ecb_encrypt(plain: bytes, key: bytes):
    cipher = AES.new(key, AES.MODE_ECB)
    return cipher.encrypt(pad(plain, AES.block_size))

def aes_ecb_decrypt(ciphertext: bytes, key: bytes):
    cipher = AES.new(key, AES.MODE_ECB)
    return unpad(cipher.decrypt(ciphertext), AES.block_size)
```

**3. Шифрование/дешифрование по AES-CTR**

```python
def aes_ctr_encrypt(plain: bytes, key: bytes, nonce: bytes = None):
    if nonce is None:
        nonce = get_random_bytes(8) 
    cipher = AES.new(key, AES.MODE_CTR, nonce=nonce)
    ciphertext = cipher.encrypt(plain)
    return ciphertext, nonce

def aes_ctr_decrypt(ciphertext: bytes, key: bytes, nonce: bytes):
    cipher = AES.new(key, AES.MODE_CTR, nonce=nonce)
    return cipher.decrypt(ciphertext)
```

При реализации AES-CTR мы использовали **nonce** - случайное смещение. Оно нам поможет создавать уникальные шифротексты даже при шифровании одних и тех же данных одним и тем же ключом. Суть в том, что при каждом запуске nonce - это разное значение, которое генерируется следующим образом:

```python
meta_data["nonce"] = os.urandom(8).hex()
```

Заметьте: мы не случайно задаем значение nonce именно таким образом, поскольку все основные данные для запуска программы мы достаем из специального файла - **meta.json**. Он выглядит вот так:


Здесь мы можем поменять два параметра - "algorithm" и "source". Подробно это мы описали в README.md
